Windows EFS job registry 采用有界不可变 blob/独占 commit marker 链，未提交 orphan 可诊断忽略，损坏已提交链拒绝。逻辑 sourceJobId 链只允许一个后继；取消的恢复 head 仍是已发生事实，祖先不能绕过它重新续作。资格和恢复选择使用 opaque ID/检查点 SHA，必须重新预览批准。
