# CW-02：三维主动/被动杆静力原生基础

日期：2026-10-11。范围为三维 TRUSS1 主动压电杆与机械普通杆共同装配的静力基础；完整动态、混合拉索、环形天线控制和简易 GUI 属于后续任务。

## 用户场景与物理定义

主要压电场景是主动杆替换桁架杆件或其中一段，而非仅在宿主上粘贴贴片。轴向伸缩受到整结构约束后产生杆端力。当前本构采用端电压约定 `V=phi2-phi1`，故电场为 `-V/L`，相应 `N=k*delta+g*V`、`Q2=Ce*V-g*delta`；自由伸长为 `-g*V/k`，阻塞力为 `g*V`。机械节点共用不代表电极短接。普通杆没有电学端口，其电荷数组的零只是兼容占位。

## 验收映射

- CW-02-A01：`passiveElementIds` 显式分类，非空混合分类要求每个 TRUSS1 完整、唯一且与主动端口不相交。格式 1.3.19 保存分类；ASCII/binary 往返、旧版读空、降版拒绝、截断/非法尾部保持原对象、陈旧分类指纹拒绝均有测试。旧空列表保留历史全主动模式。
- CW-02-A02：斜向三维杆的自由/阻塞与反向端点、异材料串联、非共线闭合三角桁架，与独立轴向本构及节点平衡解析参考比较。三角模型是最小闭合静力参考，不能冒称完整环形天线。真实 `fea-solver` 子进程读取 RAM/RBM 并写实际编号结果文件；测试读回实际结果比较位移、轴力、应力和电荷，不以输入或结果链接冒充求解结果。
- CW-02-A03：普通杆参与刚度、内力、应力和机械能；不配置虚构介电常数或电学支路。结果提供端口可用性；发布前校验精确物理输入指纹及结果 seal。改变 E/A/几何/载荷/电压/边界或实际节点热场、同尺寸外来结果、有限数值篡改或手工结果，在第一次模型修改前拒绝。seal 为本地一致性约束，不是可信认证机制。

## 兼容和负例边界

缺失分类的原生 CLI 反例目前由模型 writer 的预检在启动子进程前拒绝；它证明非法输入没有成功结果，不宣称该负例实际启动了求解器。正例确实运行两个实际 CLI 子进程。当前混合模式限定 LegacyTerminalVoltage；NodalPotential 的普通杆混用明确拒绝，不添加普通杆虚构电自由度。
