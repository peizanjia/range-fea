- 明确撤销：只留结构功能的草案、误拟TC09–12扩展；保留决策来源而不复活废案。
- 技术替代：Gmsh C++ ABI→C API、MATLAB stdin→TCP；旧失败是排查历史，不是当前全无能力。

- 暂停/阻塞：额度、用户退出、系统权限、WF10–12及产品终验；不因停过或旧日期删除仍有目标的资料。
- 一次性工具退役：11月5日定向调查runner；本轮结束其维护，底层测试、数值运行时、历史日志及后继全链入口保留。
