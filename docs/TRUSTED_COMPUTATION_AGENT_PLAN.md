### ProblemSpec v1 接口

根應用服務接口為 `RTrustedMechanicsService`，輸入/輸出使用 Qt JSON 對象，候選模型在獨立 `RModel` 中建立。根字段採嚴格白名單；未知字段返回 `SPEC_FIELD_UNSUPPORTED`，避免把未建模物理量靜默丟棄。

最小軸向杆靜力規格示例：

```json
{
  "schemaVersion": 1,
  "modelType": "axialRod",
  "geometry": {"length": {"value": 1, "unit": "m"}, "segments": 8},
  "material": {
    "name": "Steel", "source": "user-supplied reference",
    "youngModulus": {"value": 210, "unit": "GPa"},
    "poissonRatio": 0.3, "density": {"value": 7850, "unit": "kg/m3"}
  },
  "section": {"area": {"value": 100, "unit": "mm2"}},
  "analysis": {"kind": "static"},
  "supports": [
    {"selector": {"kind": "fixedEnd"}, "dofs": ["ux", "uy", "uz"]},
    {"selector": {"kind": "allNodes"}, "dofs": ["uy", "uz"]}
  ],
  "loads": [{
    "kind": "pointForce", "selector": {"kind": "freeEnd"},
    "components": [
      {"value": 1000, "unit": "N"},
      {"value": 0, "unit": "N"},
      {"value": 0, "unit": "N"}
    ]
  }],
  "initialConditions": [],
  "observables": [{"selector": {"kind": "freeEnd"}, "quantity": "displacement", "component": "ux"}],
  "precision": {"displacementRelative": 0.01}
}
```

`cantileverBeam` 的 `section` 還需提供 SI 可轉換的 `iy`、`iz`、`torsionalConstant`、`wy`、`wz`、`wt`，以及 x 軸梁的單位方向 `localY`。幾何模板固定沿全局 x 軸、從 x=0 開始。選擇器為 `fixedEnd`、`freeEnd`、`allNodes` 或帶顯式長度單位 `x` 的 `position`；`position.tolerance` 可選，省略時只允許浮點尺度內的貼合。點力必須選中單個物理節點，不能用 `allNodes` 把合力複製到每個網格節點。候選建立和 `inspect` 都回報當前模型修訂號、節點位置與物理 ID；位置不能解析時建模拒絕。

線彈性材料必須明確提供來源、E、泊松比和密度。量綱錯誤、非有限或不支持單位被拒絕。當 `analysis.kind` 為 `linearTransient`，還需提供正時間步與步數、顯式 Rayleigh `damping.rayleighAlpha`（頻率量綱）和 `rayleighBeta`（時間量綱），以及至少一條顯式初始條件；零阻尼/零初值需明確填零。可選點力歷程的時間戳必須非負、嚴格遞增且不超過總時長。瞬態採用 Newmark；其時間步/步數在數值摘要中，總時長與阻尼在物理摘要中。

SI 轉換表目前包括長度 m/mm/cm/km/in/ft，面積 m²/mm²/cm²，慣性矩 m⁴/mm⁴，截面模數 m³/mm³，力 N/kN，應力 Pa/kPa/MPa/GPa，密度 kg/m³/g/cm³，時間 s/ms，頻率 Hz/1/s/s⁻¹，速度 m/s/mm/s，角度 rad/deg 及角速度 rad/s/deg/s。表外單位明確拒絕，不能按單位字串猜測。

## 階段 5：誤差驅動自動收斂

網格與時間步研究分開，各最多 4 級；固定物理摘要，比較指定位移、應變能、頻率與時域量；不以集中力處應力峰值作主要收斂量。連續兩次變化低於 1% 且物理驗證通過才報達成本任務標準；預算到時回報未收斂。提供曲線、成本、停止理由及解析解真實誤差。

## 階段 6：Agent 全流程調度

按查能力→理解/補問→建模→診斷→求解→驗證→修復/收斂→報告調度已驗證工具。分開呈現工具事實和模型推斷；超限、非法參數循環或不可靠調用時停止並保留任務。使用現有配置模型，不新增微調。完成杆/梁端到端、自動數值修復和需詢問案例；數值可追溯，驗證器失敗時明示失敗。

## 階段 7：對照試驗

比較自然語言直出、工具與錯誤回饋 Agent、完整診斷/修復/收斂系統三組；12 個正常與 8 個故障任務，每組 3 次，共 180 次。開發和最終案例隔離，模型與資源一致；記錄物理正確完成、錯誤接受、診斷/拒絕率、誤差、人工介入、修復/求解次數、耗時和重複穩定性。保留失敗，不預設完整系統勝出。提供第三方重跑配置。

## 階段 8：課程交付與來源/知識產權準備

凍結版本並記錄倉庫、子模組、依賴、模型配置和工件身份；新安裝目錄驗證建模到報告導出。保留上游說明/許可，記錄新增模組與 AI 協助；不把整個 Range 平台聲稱為個人原創。整理推導、測試集/原始記錄、報告/答辯材料和軟著草稿；專利候選另行檢索，功能完成不等同新穎性。
