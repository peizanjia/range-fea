# WF-14 几何、网格与静态重绑验收记录

**结论：首批受限范围验收通过；完整产品发布仍未完成。** 几何支持 POINT/TRUSS1/BEAM1 显式物理节点坐标（m）和整体右手刚体轴角（deg）变换。网格支持单一连通、凸、向外闭合 TRI1 壳与均匀材料，生成线性 TETRA1；不支持通用 CAD、非凸/多区域自动网格或猜测跨网格映射。

Mesh worker 只读冻结输入，绑定文件、参数、运行上下文和固定程序 hash。接受生成网格会创建新文档和新物理节点/单元 ID，清除旧载荷、控制、结果、ROM/派生映射并设任务为 NONE。显式 `mesh.rebind.static` 只对已验证的未绑定四面体网格建立 SI 材料、全局节点支持/力与原生静力任务；旧结果始终指向旧来源。

产品实现冻结于 `c83bf5a4ebd5fde57420e281c2b1c2a3b63b254b`，Release 全回归 179/179、0 失败、1569.51 秒。测试/验收冻结 `664ea7b43dcebad5f423e85a877f0e12211267e2` 只改测试与测试编译定义，产品代码仍为 c83；补充的三项目标 3/3、0 失败、0 跳过、104.59 秒，其中 `tst_mesh_binding_widget` 用时 76.42 秒。私有安装目录的 Mesh SDK 测试 9/9（1.880 秒）。GUI harness 在安装目录之外，但调用安装内 SDK/Python/Qt/native 工具；这不等于独立安装包或干净机器验收。逐项证据见[集成验收清单](integrated-20261010.json)。
