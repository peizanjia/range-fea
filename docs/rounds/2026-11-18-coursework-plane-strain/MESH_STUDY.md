# 结构化网格验证与计算任务的可选网格研究

## Range 的当前能力

- 本作业初算使用 Gmsh 非结构化 **TRI3**，独立复算使用 **TRI6**，网格加密位置和尺度由人指定。后续按计划生成四级结构化 **QUAD4** 并用 Range 原生静力求解。
- Range 的面单元注册表和装配支持 QUAD4、QUAD9 平面应变。已有 [QUAD4 平面应变条带解析测试](../../../src/range-solver-lib/tests/tst_solver_stress.cpp#L1662) 和 [Gmsh 映射四边形生成测试](../../../src/range-model-lib/tests/tst_mesh_pipeline.cpp#L85)。可选 Gmsh 模型库 API 支持简单矩形的分向网格数、偏置、transfinite 映射和重组。本地 Linux 构建的 `RANGE_GMSH_ROOT` 为空。本次用脚本生成多块四边形，通过原生文件载入模型和求解，用于核对多块四边形的原生求解。
- GUI 的 [网格尺寸函数](../../../src/fea/src/mesh_generator_dialog.cpp#L74) 可从已有结果变量生成尺寸场，为人工细化提供入口。可借鉴 [候选网格](../../../src/range-application-lib/include/rmesh_candidate_service.h) 和 [重绑](../../../src/range-application-lib/include/rmesh_rebind_service.h) 的隔离及验收思路。现有 WF14 契约针对受限单区 TETRA1，五材料二维模型需要自己的几何组与边载重绑契约。
- 目前没有本题所需的通用多区结构化 GUI 划网与计算任务级自动加密循环。本轮备有独立计算验证和外部敏感性检查。QUAD9 与 GUI 从头建模留待单独验证。

## 同一课程模型的结构化 QUAD4 实测

按材料界面、台阶及荷载断点分块，每块采用逻辑 i、j 网格。公共边共享节点和分段，保留两级 45° 坡面、E 区嵌入和完整荷载长度。四级模型由 Range FEA 1.3.0 原生 CLI 求解，另用 Python 装配双线性 QUAD4、2×2 高斯积分并作稀疏直接求解。各级均校核面积、释放自由度残差、力与力矩平衡，以及同网格位移。

最细级 120,901 个节点，所有积分点 Jacobian 行列式为正，底面反力 7,565.06 kN。全场位移与独立同网格直接解最大差 1.63e−10 mm。三个监测点六个分量分别与最细 TRI3、独立 TRI6 最大相差 0.00073、0.00132 mm。以 0.01 mm 作为本例演示阈值，最后两次加密均通过。

**监测限制。** 四级原生日志都将 P2 报为模型外。P2 在四级网格都是 (26, −2) 的精确节点。原生监测通过 `RElement::isInside` 找包含点的单元，当前点定位和插值分支缺少 QUAD。P1、P3 恰好在已有的载荷 LINE 上，原生日志记录了它们。本轮对 P2 直接读取原生节点位移，并和独立解比较。一般位置的 QUAD 监测需用等参逆映射定位，再用同一组形函数插值，测试应覆盖点、边、内部、扭曲单元和外部拒绝。见 [单元点定位](../../../src/range-model-lib/src/rml_element.cpp#L1010) 与 [求解器监测入口](../../../src/range-solver-lib/src/rsolvergeneric.cpp#L1392)。

## 计算任务可选项

在静力任务的外层增加“网格研究”，保留常规的单网格求解路径。首版可以设“固定级数敏感性”和“达到容差停止”两种运行方式，目标量按坐标、几何面/边和积分区域定义。第二阶段增加真正的基于误差的局部加密，两者共享比较和报告接口。

| 方法 | 怎样决定下一轮 | 适用范围 |
| --- | --- | --- |
| 系统 h 加密 | 用同类单元按给定比例收细，例如 h、h/2、h/4。比较固定目标量。至少三级且呈渐近规律、阶次可合理估计时，可报告 Richardson 外推与 GCI | 实现成本低，适合作为首版及基准。局部非规则网格和奇异峰值应先检查外推假设。 |
| 残差估计与 Dörfler 标记 | 用单元内部平衡残差 f+div σ、内边牵引跳量和 Neumann 边牵引残差构造每个单元的指标 η_K。按 η_K² 从大到小选到累计占比达到 θ，然后局部缩小 h | 通用静力 h 自适应的基线。材料刚度差大时需验证指标权重，材料界面比较法向牵引 σn。 |
| Zienkiewicz–Zhu 恢复 | 同材料单元邻域拟合较平滑的应力场，用恢复场与有限元应力的差估计能量范数误差 | 易于获得局部指标。恢复区按材料分开处理，避免平均掉真实应力跳变。 |
| 目标导向自适应 | 为选定目标解伴随问题，用伴随量给局部残差加权 | 用户只关心某个区域平均位移、支座反力或应力积分时更聚焦。宜先使用固定物理尺度的平均量。 |

每轮执行 `网格候选 → 几何与质量检查 → 重绑 → 求解 → 提取目标量 → 误差或级差评估 → 细化或结束`。逐轮保留网格参数和指纹、自由度、坐标/区域的取值来源、反力平衡、求解日志和指标。先确认本级求解成功，再比较目标量。位移等目标采用带量纲绝对容差和相对容差，项目可设连续两次满足。用户能限制网格级数、自由度、最小尺寸和时间。达到预算、缺目标量或重绑失败时，分别报告原因并保留上一份有效结果。发布候选前要复核材料面积、边载合力与力矩、支承以及探针坐标。

结构化 QUAD 首版适合按块调密，公共边分段变更向相邻块传播，保持共形。后续若用 1→4 局部拆分，需要定义悬挂节点约束或共形过渡。自由划分 TRI 可对被标记单元及邻域生成尺寸场后重网格。尖角最大应力可帮助定位，停止量使用固定物理距离应力、固定区域平均值、反力或位移。本题 σzz 恢复和 QUAD 点定位要在自动应力监测中纳入验收。
