# 课程大作业 R | 平面应变算例核验

这是一道五材料、小变形线弹性静力题。Range FEA 1.3.0 原生求解器完成了五级网格计算，原生监测文件给出了三个蓝点的位移。完整平面应变应力由 Range 的位移场恢复。独立 SciPy 稀疏直接解用于校核同网格结果。

## 题图解释与输入

- 以左边界为 x = 0，右为正，以地表为 y = 0，上为正，单位为 m。按图中阴影，约束左、右边界的 Ux 和底面的 Uy，地表及台阶坡面保留自由，受载段施加压力。所有表面节点的 Uz 为零。取单位面外厚度 1 m。
- A 在 x = 0–12、y = −2–0，B 在 x = 0–12、y = −4–−2。C 的外包矩形为 x = 0–40、y = −9–−4，扣除 E 的嵌入部分。E 紧贴 A/B 右侧，取 x = 12–12.4、y = −7–0。D 下阶坡脚为 (24, −4)，坡顶为 (26, −2)。上阶坡脚为 (31, −2)，坡顶为 (33, 0)，两阶均延伸至 x = 40。A/B/C/D/E 的实际面积依次为 24、24、198.8、46、2.8 m²。
- 材料界面取完全黏结，相邻区域共用节点。自重从无初始应力状态与表面荷载共同施加。取学号末两位 37，得到下向压力 137 kPa，分别加载到 x = 3–9 和 x = 33–36.5 的零高程边。重力加速度取 (0, −10, 0) m/s²。
- P1 取 (6, 0)，P2 位于下阶坡顶 (26, −2)，P3 取 (35.1, 0)。P1、P3 是基于示意图的位置约定，P3 按 7 m 上平台的图示比例估读。两处地表监测由边上插值得到。

## 监测位移与收敛

最细网格有 138,064 个节点和 274,052 个 TRI3。全场位移模量最大约 34.645 mm。正 Ux 表示向右，负 Uy 表示下沉。

| 网格目标尺寸 m | TRI3 数 | P1 Ux mm | P1 Uy mm | P2 Ux mm | P2 Uy mm | P3 Ux mm | P3 Uy mm | 恢复的峰值等效应力 kPa |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.80 | 2,437 | 1.6533 | −34.6147 | −0.8199 | −3.0980 | −0.8393 | −20.6251 | 682.8 |
| 0.40 | 6,214 | 1.6277 | −34.5833 | −0.8015 | −3.0968 | −0.8526 | −20.7146 | 675.0 |
| 0.20 | 17,729 | 1.6172 | −34.5910 | −0.7932 | −3.0965 | −0.8355 | −20.7797 | 676.3 |
| 0.10 | 68,998 | 1.6256 | −34.5934 | −0.7912 | −3.0965 | −0.8362 | −20.7945 | 860.1 |
| 0.05 | 274,052 | 1.6285 | −34.5944 | −0.7903 | −3.0963 | −0.8359 | −20.7967 | 928.3 |

- **平衡。** 每米厚度的自重为 6,263.56 kN，地表载荷为 1,301.50 kN，底面竖向反力为 7,565.06 kN。Range 输出的 Force 是内部弹性节点力，反力按约束自由度扣去该处外载后计算。最细网格的水平、竖向合力误差绝对值分别小于 0.000004 N 和 0.000002 N，绕 (0, 0) 的力矩误差约 0.000010 N·m。独立刚度矩阵回代得到自由自由度相对残差 5.59e−10，约束自由度位移为零。
- **独立复算。** 在同一网格独立组装 BᵀDB、重力体力与线段边载，消去约束自由度后用 SciPy 直接求解。最细网格全场位移分量最大差小于 0.000001 mm。同一 Range 位移用独立矩阵计算的节点内力与 Range Force 最大绝对差小于 0.000001 N。两种方法都采用相同的小变形线弹性假设。
- **离散误差。** 最细两级网格的监测位移分量最大绝对变化 0.0029 mm、最大相对变化 0.18%。等效应力在 A–D 各区的面积加权均值变化均小于 0.03%，E 区均值变化约 1.04%，E 区局部峰值涨约 7.9%。尖角、刚度突变和载荷端点附近的单元应力受网格影响。本轮支持报告位移和应力分布，峰值尚未收敛。
- **测点位置敏感性。** P1 横向移动 ±0.25 m 时，Ux 为 1.52–1.74 mm，Uy 为 −34.61 至 −34.53 mm。P3 横向移动 ±0.25 m 时，Ux 为 −1.08 至 −0.60 mm，Uy 为 −20.86 至 −20.59 mm。示意图定位误差可能高于离散误差。
- **应力恢复。** 各向同性线弹性、εzz = 0、无热应变时，σzz = ν(σxx + σyy)。计算完整 von Mises 时纳入 σzz。最细网格恢复的最大 |σzz| 为 371.24 kPa。全局竖向正应力采用拉正压负，云图色标截在 ±250 kPa，完整场极值约为 −1,084 和 +676 kPa。等效应力云图将 350 kPa 以上标为饱和，完整单元值保存在 CSV。
