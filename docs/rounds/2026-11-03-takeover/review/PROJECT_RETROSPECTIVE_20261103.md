## 4. 2026-09-24：从旧一阶瞬态改为真正二阶动力学，再接控制器

**提出的目标：**旧结构瞬态的一阶形式不能支撑惯性、振动和控制研究，新增 `M qdd + C qd + K q = f` 路径。先交付被动动力学，再交付控制耦合。

**实施与检测：**Newmark、广义alpha、中心差分；位移/速度/加速度、阻尼、旋转初态、移动支承、重启、反力与能量功账、失败回滚。被动阶段最终Release及49/49；控制阶段C++回调、Python NDJSON实际FE、控制器/延迟/噪声状态保存，最终53/53。

**关键方案调整：**

- MPC动力/模态初版存在奇异质量问题，采用约束消元；不把拒绝输入当作已支持。
- 控制器只在接受状态推进一次，不在求解迭代里改变历史；本步保持新力前刷新起点加速度，避免误作斜坡力。
- 固定有效算子缓存用于减少成本；小模型多线程反而较慢，保留测量而不宣称普遍加速。
- 旧对象混用导致OpenMP异常，以clean-first重建处理；部署与测试冲突后串行执行。

**未完成：**每步复制/重装配成本没有全消除；无硬实时或板卡验证。MATLAB R2022a可batch启动，但stdin常驻握手失败，当时只能接受C++/Python控制路径。
