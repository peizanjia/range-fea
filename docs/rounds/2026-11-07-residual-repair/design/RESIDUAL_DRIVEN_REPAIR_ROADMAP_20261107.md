## 执行摘要

用户只需定义关心的结果、允许误差和试算预算。软件应自动识别求解失败、离散误差、模型定义疑点和证据缺失，选择一项能够区分原因的低成本试验，在隔离候选上复算。适用性、修复权限及结果验收由 Host 判定，DeepSeek Pro 负责理解目标、安排可执行检查、解释证据和提出必要问题。用户一次授权一组有界数值试验，最后审阅推荐候选。涉及物理定义和模型拓扑语义的选择单独确认。

四杆 PZT 已提供直接证据。66 步结果的端点自由自由度力残差为 4.77×10⁻¹⁵ N，同输入 RK4 回放的峰值位移差仍为 1.60×10⁻¹² m。相对本次预先在复算任务中声明的 1×10⁻¹² m 目标，该差值需要处理。保持物理时窗与控制采样周期的半步长复算将差值降到 4.02×10⁻¹³ m。这里的触发证据是轨迹差超目标，力残差用于排查另一类问题。已验证的在线流程使用已存基准收据和测试审批回调。下一步应让 Host 自己串起基准、诊断、候选、预算和终态核验。

## 一次诊断需要哪些证据

令离散系统为 \(A_h x_h=b_h\)，实际求得 \(\hat{x}\)。残差 \(r=b_h-A_h\hat{x}\) 反映已组装离散问题的代数不平衡。可用 \(\|r\|/(\|A_h\|\|\hat{x}\|+\|b_h\|)\) 衡量尺度化后向误差，并结合条件性或物理尺度判断解的敏感度。即使 \(r=0\)，离散解与连续问题的解仍可能相差很大。Krylov 内部预条件残差和独立重算的真实残差应分列。近零 QoI 应采用有单位的绝对门限或预声明尺度。多场量分块记录，避免力、力矩、电荷混为同一个范数。[PETSc KSP](https://petsc.org/release/manual/ksp/)，[Higham 与 Higham](https://epubs.siam.org/doi/abs/10.1137/0613014)

| 诊断层 | 需要组合判断的信号 | 最便宜的区分试验及动作 |
|---|---|---|
| 求解状态与代数误差 | 真残差、迭代历史、更新量、矩阵性质、约束秩、条件性代理、终态原因 | 在同网格、同物理下收紧内层误差或更换适用的预条件器。达到迭代上限且仍稳步下降时才试增加迭代上限。缺支承或近零刚度先检查零空间 |
| 非线性推进 | 残差平台或振荡、更新量、线搜索、切线失配、拒绝步与加载路径 | 对已支持的求解器试更新切线、线搜索或缩小静力增量。遇到分岔、跳跃或多解，保留路径及稳定性信息，升级人工审阅 |
| 时间误差 | 时间误差估计、相位与峰值、功／能、步长比较、力和控制采样事件 | 固定空间与物理，试半步长。同控制周期、时窗和事件对齐。参考积分先检查自身子步收敛。同输入回放与闭环复算分开报告 |
| 空间误差 | 同位置 QoI 的三层变化、单元强残差和内面通量／牵引跳量，或对偶加权贡献 | 固定时间和求解器，先做有界整体细化诊断。有经资格验证的局部指标后才按标记区加密。尖角点应力发散时报告奇异性，另行确认有限域平均或其他 QoI |
| 模型、控制与数据 | 约束反力、边界／载荷、材料和单位、端口极性、初始工作点、控制饱和与 KKT、参考来源 | 核对物理声明、参考和原始轨迹。改材料、支承、激励、几何、阻尼或控制目标需独立批准。来源错配、证据缺失和 I/O 故障分别处理 |

静力残差应区分自由 DOF 平衡和约束反力。模态另查归一化、正交性和频率簇。网格间使用同物理坐标及可比 DOF 映射匹配模态，近重根比较子空间。瞬态同时区分离散步平衡、时间推进误差和输出采样误差。压电检查电荷、施加电压与端口边界并核对预应力。MPC 的 KKT 证据用于优化子问题，不能替代 FE 或控制效果验收。

## 智能化与权限

界面提供一个「检查并改进」入口，从当前文档预填分析族、可用 QoI、选择器和单位。精简模式只显示目标、容差、资源上限和可自动尝试的动作。用户未指定精度时，可先生成诊断和收敛证据，界面展示有出处的模板建议，用户确认后才给任务级达标结论。需要提问时只问决定下一步的信息，例如峰值应力还是支承附近平均应力。

- **自动只读。** 校验源、读取日志、分块重算、分类、给出证据不足原因和可区分原因的试验。用规则和证据链输出「确认」「候选原因」「不可判断」。LLM 解释和排序，不能改事实或判据。
- **一次授权的数值试验。** 固定物理摘要、QoI、阈值、版本、候选字段、资源和终止条件。允许在隔离候选内自动执行已授权动作。初期建议一个修复轴、最多两次修正、总共最多三次求解；按网格 DOF、接受步数、内存和墙钟分别设限。此为拟议默认值。
- **逐项批准。** 网格候选替换原文档、复杂语义重绑定、求解器路径可能跨分支、控制器重新设计及任何物理变更。数值阻尼和物理阻尼分别管理。控制增益、MPC 权重或时窗变更应当属于控制设计，不能归入数值修复白名单。
- **拒绝或停止。** 来源过期、模式不支持、缺失关键工件、预算不足、不改善、不同 QoI 相互恶化、疑似奇异或模型含义不确定。保留基准和最后一个通过的候选。不能用放宽容差、删失败指标、改变负载或换 QoI 达标。

状态沿用 Trusted Experiment 作业与审批语义。每次候选保存基准 revision、物理摘要、网格／求解配置摘要、父工件、结构化变更、规则版本及输入输出摘要。每项检查含值、单位、尺度、门限、覆盖和来源，状态为 `pass/fail/not_computed/not_applicable`。先保证可比较，再检查全部必检项和预先设定的目标。没有参考时允许报告「相邻变化稳定」，与「绝对误差达标」分列。一次只改变一个误差轴；若改善接近噪声或误差被抵消，追加独立交叉试验或停止。只发布通过 Host 复核的候选，保留撤销和复现路径。
