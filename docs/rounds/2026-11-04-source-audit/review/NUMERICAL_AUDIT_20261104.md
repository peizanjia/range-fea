## 确认问题：强轴向响应可掩盖梁转角平衡错误

位置：`src/range-application-lib/src/rtrusted_verification_service.cpp` 的静力 `staticResidual` 分支。

原公式为：

```
max_i |(Kq-f)_i| / max_i (|f_i| + sum_j |K_ij q_j|)
```

分子与分母可能来自不同自由度，梁平移方程使用N、转角方程使用N·m；强轴向行还可能掩盖同单位的弱弯曲行。已有解析位移检查只比较各平移分量，不能补上转角的逐行平衡检查。总应变能与外功的相对误差也可被强轴向能量掩盖。

构造性触发条件为两段直悬臂，L=1 m，E=210 GPa，A=1e-4 m²，Iy=1e-8 m⁴，端力 `[1e3,0,-1e-9]` N。先按解析解填写所有节点平移与转角，再仅给末端ry增加 `5e-8` rad。夹端及其相邻节点未改，因此支座反力与总平衡不变；平移也保持解析值。

代数估算：原最大方程尺度约4e3，最大新残差约2.52e-3 N，旧比例约6.3e-7，低于固定1e-6门槛；轴向能量约2.38e-2 J，新增弯曲能量约2.1e-11 J，不足以触发全局能量门槛。弱弯曲行本身的归一化残差则接近1，应被拒绝。上述数值是公式推导，未执行旧版本或新版本测试。

## 本次修复

改为逐自由方程计算，再取最大值：

```
max_i [ |(Kq-f)_i| / (|f_i| + sum_j |K_ij q_j|) ]
```

保留原1e-6阈值及全部独立位移、支座、能量和身份检查。尺度为零时要求残差严格为零；非有限残差或尺度明确失败。证据字段 `normalizedResidual` 现在明确表达最大逐行误差，理由文本同步说明公式。

新增 `rejectsWeakAxisRotationMaskedByAxialForce` 回归源：先发布完整解析梁的真实原生工件作为正例，再发布末端转角篡改但哈希有效的独立工件作为反例。断言身份/模型支持/平移/总反力平衡/应变能检查仍通过，而逐行静力平衡拒绝，且整份报告失败。该用例使用现有原生broker文件发布和重新读取路径，不向验证器直接注入数值DTO。
