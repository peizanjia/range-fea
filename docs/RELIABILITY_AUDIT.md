## 源码审查发现（修复前）

- `reigenvaluesolver.cpp::solveSubspaceIteration()` 已检查特征值变化与广义残差，但到达迭代上限只记录警告，仍返回 Ritz 对；`solveInversePowerIteration()` 仅按特征值变化停止，未以向量残差认证结果，也不在耗尽迭代时失败。`RSolverStress::solveEigenValue()` 直接消费这两个路径，需补失败关闭与反例。现有模态阻尼另有残差护栏，不能替代普通模态求解入口的验证。
- `tst_structural_dynamics_integrator` 已检验 Newmark/中心差分二阶时间收敛、解析自由振动与能量；广义 alpha 的当前测试只涉及低频单自由度近似与有限能量值，不能单凭该测试证明高频选择性耗散。
- `RSolverStress` 的桁架路径只有材料刚度与热应变项，没有 Stage 7 所需的初应力几何刚度。已有 `ElectricPotential` DOF 描述不代表机械专用状态/约束/控制路径支持压电耦合。
- Stage 6 Python CLI 测试证实非零命令与事件链，但尚无独立进程中断/恢复和不中断全程的逐步对照，应在扩大控制耦合前补齐。

## 积分公式独立核对

广义 alpha 的 `am=(2rho-1)/(rho+1)`、`af=rho/(rho+1)`、`gamma=1/2-am+af`、`beta=(1-am+af)^2/4`，以及 `t_n+(1-af)dt` 外力时刻，与 [Sandia 结构动力学报告](https://www.osti.gov/servlets/purl/1820245) 中的 Chung–Hulbert 约定相符。其他实现可能采用 `1-am`、`1-af` 作为参数名，比较时必须同时比较新旧状态的权重。

高频谱半径控制属于线性放大矩阵性质；不等同于每一步物理机械能都单调下降。现有梯形外力功和阻尼功率积分是能量诊断口径；新增测试将检查分离高低频响应与时间步收敛，不强加不适用的逐步能量单调断言。
