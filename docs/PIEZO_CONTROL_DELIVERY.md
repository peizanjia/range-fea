## 交付目标与默认操作

交付实际 Windows 软件：配置压电作动／传感杆和理想粘结梁／平板贴片后，以同一修改后的有限元模型完成正压电信号、质量／刚度／用户阻尼、模态选择与矩阵导出、FE／ROM 状态空间、有模型／无模型控制、自由／受迫振动、结果和完整恢复。

首要卖点仍是功能完备且交互简单。一个实验集中配置模型、器件／端口、模态／矩阵、控制器、激励／结果；全部模型与运行更改一次整体预览确认。保存且未改变的实验以“运行＋确认”两项主动操作启动。软件自动处理物理 ID、矩阵行列映射、状态投影、端口单位、工件路径和版本摘要；不要求用户手写连接代码。

本次完整功能以以下支持矩阵验收：三维轴向压电替换杆；可在三维空间任意取向的平面轴向—弯曲分层梁及理想粘结贴片；平板的膜／弯曲／剪切分层 Q4 内核及其贴片；机械／压电混合源。梁明确局部平面、两平移和法向转角；扭转、翘曲、另一平面弯曲及对应载荷／初值／DOF显式拒绝，不包装成一般3D框架。支持运动学的完整平移／转角和偏心交叉 M 必须进入实际FE；旋转等价与非法自由度负例必测。现有 TRI／QUAD 面内应力入口保持原语义。平板使用真实板网格，软件提供生成入口；不能将现有面内 TRI 单元冒充板弯曲。曲壳、任意三维压电实体、脱粘与胶层损伤属于后续扩展，不用本次结果宣称已验证。

当前真实控制后端消费有限元节点、元素与边界；可由已支持的几何原语生成网格后进入同一路径。STL／TetGen 体网格与有限几何网格工具存在，但没有已核实的任意 STEP／IGES 面身份跨重网格保持链。因此本次先实现节点时间激励和对应外部函数，连续面／体载荷与完整 CAD 面绑定保留后续。载荷并非必须在 CAD 上定义：FE 边界／域也可正确积分成等效节点载荷。

LiveLink MATLAB 与 Simulink 分别保留对照，用户已允许无现成算例时暂不实测。本次不以该缺项阻塞功能开发；不虚构相对点击数或优势。本软件自身真实点击／输入项／重复配置与窗口证据必须完成。

## 物理与数值决策

统一原生组装 `M, K^E, G, Ce, f`，而不是另建一个仅用于控制演示的小模型。令 `V=phi(+)−phi(−)`，正电极自由电荷为 `Q`：

线性源在零参考下为 `M*qdd + C*qd + K^E*q + G*V = f`、`Q = Ce*V − G^T*q`。有预应力／偏置时，持久化同一平衡工作点 `q0,V0,Q0,f0`，先验证力残差；ROM 与模态使用增量 `deltaq=q−q0` 等。`K0` 是实际工作点的完整力学／电学切线，包含适用的预应力几何项，不能用材料刚度替代。矩阵导出区分材料块、几何块及凝聚后切线；信号同时提供绝对读数和工作点增量。杆／索的非线性现有路径保留，梁／板首批为小变形原生完整 FE，明确工作点线性化的适用范围。

轴向杆替换原构件，不能重复宿主质量／刚度。梁／板贴片共享宿主运动学，完整层积分包含贴片质量、自身二次矩、偏心、膜—弯曲耦合和电极；覆盖多个元素的连续电极组装到同一端口。局部贴片边界若需分区／重网格，由软件提出并重绑定，不让用户手工解决节点不重合。

压电传感不是把节点位移换一个名称。提供：

- 理想开路电压：只凝聚固定增量总电荷的传感子集 `s`，不把电压作动端口 `a` 当作开路。工作点增量为 `deltaVs=Css^-1*(deltaQs+Gs^T*deltaq−Csa*deltaVa)`；`Keff=K0^E+Gs*Css^-1*Gs^T`，有效电压耦合 `Gaeff=Ga−Gs*Css^-1*Csa`。首批不同端口电气隔离，`Csa=0`；同一连续电极覆盖多个元素可合并，未实现的共享电路显式拒绝。`deltaQs=0` 时输出绝对 `Vs0+deltaVs` 及增量，初始电荷偏置持久化。
- 理想短路／电荷读出：`V=0`，测量 `Q=−G^T*q`，使用短路刚度。
- 理想电荷放大器：虚地电极和明确反馈电容 `Cf`，由转移电荷输出电压；标注理想读出模型。
- 致动端口电荷：包括电容直接项 `Ce*V`；理想电压源端电压标为动作记录，不作为独立变形测量。

真实放大器泄漏、输入阻抗、线缆电容和带宽需要额外电路状态，不能用理想选项宣称完整硬件调理链。材料库区分 `c^E/e/epsilon^S` 与 `s^E/d/epsilon^T`，一致转换 `e=d*c^E`、`epsilon^S=epsilon^T−d*c^E*d^T`，再按梁／板横向自由应力条件减缩。示例、厂商和标定来源分别显示。

每次材料、几何、贴片、极化、电极、传感电学边界、作动绑定或约束更改都重组装并使旧模态、ROM、控制增益及批准失效。导出保存操作点、残差证书、物理 DOF／约束变换、单位和源身份。

阻尼不能从 `K/M` 唯一推导。用户选择统一模态阻尼比、逐模态／模态簇阻尼比、Rayleigh 或导入 `C`；选择一种权威模型，FE 与 ROM 使用同一个 `C`。完整质量归一化模态基下可构造 `C=M*Phi*diag(2*zeta_i*omega_i)*Phi^T*M`。只取部分模态时明确 `Cr` 及高阶模态策略，不把其宣称为唯一全阶阻尼。算法耗散参数不当作物理阻尼。

模态必须验证广义特征残差、质量正交及近重根簇。用户可选择模态并可选导出 FE `M/K/C/G/Ce/B`、模态数据和 ROM 连续／离散 `A/B/Cy/D`，包含加速度、电学及扰动直接项。使用精确 ZOH 块矩阵指数，不通过 `A^-1` 计算离散 `B`。

有模型控制默认可选“仿真全状态投影”：`eta=Phi^T*M*(q−q0)`、`etaDot=Phi^T*M*qd`，每次从真实接受 FE 响应取得 ROM 状态，再输出各作动动作。另提供“仅用所选传感信号”模式，需观测器、可观性／可检测性和估计状态持久化；不得隐式读取未选择的 FE 状态。

内置控制首批包含速度反馈、PI／PID／PD、离散状态空间、离散 LQR 和约束线性 MPC。LQR 实际求解 Riccati 方程并验证残差及闭环极点；MPC 实际求解带幅值／速率约束的有限时域 QP并验证状态、可行性和 KKT。失败不给伪动作，不默默改成另一控制器。

数值后端采用可复用的现有原生矩阵／FE内核和已私有打包的 NumPy／SciPy计算能力；原生 FE 始终是真实 plant。设计时模态、矩阵指数、Riccati／QP后端须明确实际库版本、源／依赖身份、残差和许可；不能以独立参考程序或低维玩具替代正式路径。新增依赖在代码之前冻结与核查。

外部激励与控制器分开。节点激励支持常值、正弦、多频、扫频、平滑脉冲、表格和受限时间表达式；外部接口仅输入 `t`、返回命名力及单位，冻结代码／依赖／环境身份。背景 `f(t_n)` 与 `f(t_n+1)` 分别求值，控制／器件命令在 FE 区间保持；不能把末端外力当作整个区间的保持力。阻尼残差、反力、耗散及外力／电学功和恢复一起验证。
