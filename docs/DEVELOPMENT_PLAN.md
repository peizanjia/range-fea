## 1. 授权、基线与执行规则

用户已授权修订计划后按计划开发、审查、验收并自动 commit。本次授权覆盖旧交接中“停止在 Stage 9”“不进入 Stage 10”的历史限制。按依赖逐个交付，不把未来计划写成当前能力；需要真实硬件、干净外部环境或用户输入的任务单独保留，不阻塞可独立执行的软件工作。

- 起点：根 `46e7318`，模型 `baec0fe`，求解器 `535a6fb`。2026-10-01 重跑现有 Release CTest 91/91，0 失败，62.52 s；未重新构建、未重跑 MATLAB 实机或干净 Windows 安装。
- 已跟踪工作树与子模块干净；既有未跟踪 `.agents/`、`.codex/`、`AGENTS.md` 是用户配置，不混入功能提交。
- 临时脚本、构建、模型输出、原始测试和审查日志放忽略的 `build/`；长期契约、使用说明与验收结论放 `docs/`，产品代码与测试放 `src/` 对应模块。
- 每个增量按“设计边界 → 实现 → 聚焦验证 → 独立审查 → 修复 → 必要回归 → 提交”执行。涉及子模块时先提交子模块，根再提交指针及集成；不自动 push。
- 构建和测试共享目录时串行执行，避免运行时 DLL 部署冲突。性能测量独立运行，不与并行 CTest 混为性能证据。
- 不调整 Hyper-V/Sandbox/认证权限。没有实测的远程 CI、外部安装或实物硬件不得记作通过。
