## 计算逻辑与误差界限

- 受限一维热弹和节点压电路径使用从参考温度积分的热应变；热求解候选有新鲜 `A*T-b` 残差认证，机械和电荷发布受各自残差/有限性门控。自由/固定杆、热弯曲、热功率与电荷符号已有真实 FE 对照。高刚度热—压电夹具曾触发机械新鲜残差失败，详情保留在已忽略的 `build/audit-20260926/thermal-piezo-investigation.md`；现有温和尺度通过不构成任意材料尺度证明。
- 一维 Kelvin–Voigt 回热只将显式物理黏性功作为热源；不把 Rayleigh 或数值阻尼直接热化。分区 FE 与独立同步标量根的一致性已测试；常系数单体核须另以真实 FE 适配器和能量/残差基准验收，不能以同一实现重组诊断冒充独立解。
- 当前 Heat→Modal 验证温度相关材料刚度引起的频率变化；模态通用装配没有初应力几何刚度。固定自由杆冷/热频率比不证明热预应力下的横向模态变化。
- 持久物理 ID 对同一实体的增删、文件往返和稀疏场查询有效，缺失场保持缺失；现有指纹拒绝拓扑/几何变化，没有跨重网格映射算法。
- 暂态结果事务限精确 `Heat → Stress` 两叶任务；监测文件、latest link 和结果记录共用实际目标锁，但不同任务树、外部不遵守锁的写入者和跨多个独立工件的系统级原子性不在当前证明内。

## 验收口径

交付前需全目标 Release 重建、完整 CTest、实际 CLI 文件往返、针对新增分支的失败/重试测试，并核对 GUI/安装树运行。历史全量 72/72 通过于较早提交，不含本轮后续 ID、并发锁、模态、模型原子性及拉索重启增量。不能把聚焦 1/1 测试写作整个 Stage 8 完成。
