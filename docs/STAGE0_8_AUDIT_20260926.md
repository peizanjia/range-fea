## 计算逻辑与误差界限

- 受限一维热弹和节点压电路径使用从参考温度积分的热应变；热求解候选有新鲜 `A*T-b` 残差认证，机械和电荷发布受各自残差/有限性门控。自由/固定杆、热弯曲、热功率与电荷符号已有真实 FE 对照。高刚度热—压电夹具曾因百万牛顿相抵后的浮点残差被误拒绝；直接耦合核现按实际装配项给物理与稀疏残差各自加入机器精度界。解析高刚度回归与完整 Heat→Stress 高刚度 FE 聚焦测试均通过；原有非收敛拒绝测试仍通过。详情见已忽略的 `build/audit-20260926/thermal-piezo-investigation.md`。
- 一维 Kelvin–Voigt 回热只将显式物理黏性功作为热源；不把 Rayleigh 或数值阻尼直接热化。分区 FE 与独立同步标量根的一致性已测试；常系数单体核现有受限 RModel TRUSS1 双杆适配器，回传机械/热新鲜残差、可逆热交换与黏性回热能量诊断，专用测试用独立代数根及失败不发布校核。它拒绝温变材料，能量历史不写入模型，也尚未接入通用 RSolver task/CLI 派发。
- Heat→Modal 验证温度相关材料刚度引起的频率变化；另有受限静态 Heat→Stress→Modal 在 BEAM1 上从接受轴力装配几何刚度，2/4/8 单元第一横向频率分别为 39.2848/39.2306/39.2273 Hz，收敛到约 39.23 Hz 的独立梁柱解。无初应力/零初应力保持原模态路径；TRUSS2 等未支持初应力装配的活动单元明确拒绝。不能由该 BEAM1 基准推出通用非线性预应力模态已交付。
- 持久物理 ID 对同一实体的增删、文件往返和稀疏场查询有效，缺失场保持缺失；现有指纹拒绝拓扑/几何变化，没有跨重网格映射算法。
- ASCII 模型结果变量原先按默认文本流精度写出，拉索分段续算的显示速度因此偏离高精度解析值；接受态 checkpoint 自身为 17 位精度。现将所有 `RVariable` ASCII 字段作用域内设为 17 位，并用 ASCII/二进制精确往返测试验证；拉索动力仍以接受态 checkpoint 作解析/能量主认证。续算前对显示位移/速度/加速度与 checkpoint 逐分量精确核对，专用大/小分量篡改测试验证不被全向量最大值掩盖。headless QTest 使用 `QTEST_APPLESS_MAIN`。
- 对高连接度热—压电一维系统，机械新鲜残差与稀疏方程残差的舍入界现按节点相邻杆数、组装项绝对和及实际加总操作数估算。300 支杆热载荷相消的聚焦回归表明残差超过固定 `8ε` 界而处于操作计数界内；原有欠收敛拒绝测试仍通过。这是浮点误差证书的受限检验，不能将舍入界当成用户收敛容差。
- 暂态结果事务限精确 `Heat → Stress` 两叶任务；监测文件、latest link 和结果记录共用实际目标锁，但不同任务树、外部不遵守锁的写入者和跨多个独立工件的系统级原子性不在当前证明内。
